# Lucky برای اندروید

فایل نصبی: `apk/lucky.apk` (ساخته‌شده در GitHub Actions، امضاشده، آمادهٔ نصب)

## نصب

1. فایل `lucky.apk` را روی گوشی کپی کن (یا از صفحهٔ Releases دانلود کن).
2. بازش کن؛ اگر پیام «نصب از منابع ناشناس» آمد، اجازه بده.
3. برنامه که باز شد، **آدرس سرور** را وارد کن.

## آدرس سرور

این اپ فقط پوسته است؛ موتور برنامه (خواندن PDF، تشخیص فصل، ساخت خلاصه/تست/پاورپوینت)
روی Node اجرا می‌شود. دو راه داری:

**راه اول — کامپیوتر خودت (همان وای‌فای):**

```bash
cd Lucky
npm start
```

بعد آدرس شبکهٔ همان کامپیوتر را روی گوشی بزن، مثلاً:

```
http://192.168.1.5:3000
```

آی‌پی را با `ip addr` (لینوکس) یا `ipconfig` (ویندوز) ببین.

**راه دوم — یک هاست اینترنتی:** برنامه را روی Railway / Render / Fly.io یا هر VPS
بالا بیاور و آدرس `https://…` را وارد کن. مزیتش این است که هر جا اینترنت داشته باشی
کار می‌کند و اعلان‌ها و PWA هم روی https کامل فعال می‌شوند.

عوض کردن آدرس: در صفحهٔ اصلی، دکمهٔ بازگشت گوشی را بزن → «تغییر آدرس سرور».

## داخل اپ چه کار می‌کند؟

- بارگذاری PDF با انتخاب‌گر فایل اندروید (همان دکمهٔ «بارگذاری PDF»)
- دانلود پاورپوینت و خروجی تقویم در پوشهٔ `Download/Lucky`
- تم روشن/تاریک، راست‌به‌چپ، اجازهٔ اعلان
- اگر سرور در دسترس نباشد، صفحهٔ «وصل نشدم» با دکمهٔ تلاش دوباره

## ساخت دوباره

هر تغییری در `android/**` بدهی، GitHub Actions خودش APK تازه می‌سازد و در
Releases می‌گذارد:

```bash
gh run list --workflow apk.yml
gh release list
```

یا محلی (اگر JDK 17 و Android SDK داری):

```bash
cd android && gradle assembleRelease
```
