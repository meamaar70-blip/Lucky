# Lucky — دستیار مطالعه‌ی دانشجو

برنامه‌ی کلاسی دانشجو را ثبت می‌کند، PDF کتاب هر درس را می‌خواند و برای **هر فصل** به‌صورت خودکار
**خلاصه**، **تست تعاملی** و **پاورپوینت آماده‌ی ارائه** می‌سازد.

> تمام قابلیت‌ها بدون اینترنت و بدون کلید API هم کار می‌کنند (موتور محلی). اتصال به هوش مصنوعی اختیاری است
> و کیفیت خلاصه و تست را بالاتر می‌برد.

---

## قابلیت‌ها

### ۱) برنامه‌ی کلاسی
- ثبت درس‌ها (نام، استاد، کد، رنگ، یادداشت)
- جدول هفتگی شنبه تا جمعه با کشیدن‌شدن خودکار کلاس‌ها روی ساعت
- ثبت **لینک کلاس آنلاین** برای هر جلسه + دکمه‌ی ورود در داشبورد
- کارت «کلاس بعدی» با شمارش معکوس و نمایش کلاس در حال برگزاری
- خروجی **`.ics`** برای وارد کردن برنامه در Google Calendar / تقویم گوشی

### ۲) آزمون‌ها و یادآورها
- ثبت آزمون با درس، عنوان، تاریخ، ساعت، مدت، محل و یادداشت منابع
- کارت «آزمون بعدی» با شمارش روزهای باقی‌مانده در داشبورد و صفحه‌ی آزمون‌ها
- **یادآور کلاس**: چند دقیقه قبل از شروع هر کلاس (قابل تنظیم: ۵ تا ۶۰ دقیقه)
- **یادآور آزمون**: از ۳۰ دقیقه تا ۳ روز قبل (برای هر آزمون هم می‌توان مقدار جدا گذاشت)
- سه کانال اطلاع‌رسانی: اعلان مرورگر (Web Notification)، بنر داخل برنامه با دکمه‌ی ورود به کلاس، و صدای هشدار
- فایل `.ics` شامل `VALARM` است؛ با وارد کردن آن در Google Calendar یا تقویم گوشی، هشدارها حتی وقتی برنامه بسته است هم می‌رسند

### ۳) کتاب درس (PDF)
- آپلود فایل PDF یا افزودن از **لینک اینترنتی**
- استخراج متن با حفظ شماره‌ی صفحه، حذف سرصفحه/پاصفحه و شماره‌ی صفحه
- **تشخیص خودکار فصل‌ها** با سه روش به‌ترتیب اولویت:
  1. بوکمارک‌های داخلی PDF
  2. عناوین شماره‌دار («فصل ۱»، «بخش ۲»، `Chapter 3` …)
  3. تقسیم یکنواخت به بخش‌های منطقی
- ویرایش دستی عنوان و محدوده‌ی صفحه‌ی هر فصل (ادغام، جابه‌جایی، افزودن فصل)

### ۴) برای هر فصل
| خروجی | توضیح |
|---|---|
| **خلاصه** | در سه حجم «کوتاه / متوسط / مفصل» + نکات کلیدی با شماره‌ی صفحه + واژه‌نامه‌ی اصطلاحات + نقشه‌ی فصل (اگر فصل زیرعنوان داشته باشد) |
| **تست** | ۵ تا ۲۵ سؤال: چهارگزینه‌ای (جای‌خالی)، درست/نادرست و پاسخ کوتاه؛ آزمون تعاملی با نمره‌ی درصدی، تصحیح خودکار و توضیح هر پاسخ؛ ذخیره‌ی نتیجه در داشبورد |
| **پاورپوینت** | فایل `.pptx` راست‌به‌چپ: جلد، نقشه‌ی فصل، نکات کلیدی، اصطلاحات، خلاصه، پرسش‌های مرور و پاسخ‌نامه |

## اجرا

```bash
npm install
npm start          # http://localhost:3000
```

- Node.js نسخه‌ی ۲۰ یا بالاتر.
- پورت با متغیر محیطی `PORT` قابل تغییر است (`PORT=8080 npm start`).
- داده‌ها در پوشه‌ی `data/` ذخیره می‌شوند: `db.json` (داده‌ها)، `uploads/` (فایل‌های PDF)،
  `text/` (متن استخراج‌شده‌ی فصل‌ها)، `exports/` (پاورپوینت‌های ساخته‌شده).
  برای پشتیبان‌گیری کافی است همین پوشه را کپی کنید. محل پوشه با `LUCKY_DATA_DIR` قابل تغییر است.

### پیش‌نمایش HTML خودکفا

```bash
npm start                 # در یک ترمینال
npm run preview:build     # در ترمینال دیگر → فایل preview.html
```

`preview.html` یک فایل مستقل است که همه‌ی صفحه‌های برنامه (داشبورد، برنامه هفتگی، دروس، فصل‌ها،
چهار تب فصل، آزمون‌ها، تنظیمات) را با همان CSS و فونت درونی نشان می‌دهد؛ بدون سرور و بدون اینترنت
در هر مرورگری باز می‌شود. دکمه‌های آن صرفاً نمایشی‌اند (برای اسکرین‌شات، ارائه یا بررسی طراحی).

### تست دودی رابط کاربری (بدون مرورگر)

```bash
npm start            # در یک ترمینال
npm run smoke        # در ترمینال دیگر: همه‌ی صفحه‌ها با jsdom رندر و بررسی می‌شوند
```

## اتصال هوش مصنوعی (اختیاری)

در صفحه‌ی **تنظیمات** → بخش «هوش مصنوعی»:

| فیلد | نمونه |
|---|---|
| آدرس سرویس | `https://api.openai.com` یا `https://openrouter.ai/api` یا `http://localhost:11434` (Ollama) |
| نام مدل | `gpt-4o-mini` |
| کلید API | `sk-…` |

- هر سرویس **سازگار با OpenAI Chat Completions** پشتیبانی می‌شود.
- کلید فقط روی همین سرور در `data/db.json` ذخیره می‌شود و در پاسخ‌های API نمایش داده نمی‌شود.
- با متغیرهای محیطی هم می‌توان تنظیم کرد: `LUCKY_AI_URL`، `LUCKY_AI_KEY`، `LUCKY_AI_MODEL`.
- اگر درخواست به هوش مصنوعی شکست بخورد، به‌صورت خودکار با موتور محلی ساخته می‌شود و به کاربر اطلاع داده می‌شود.

## موتور محلی چطور کار می‌کند؟

فایل‌های `server/lib/`:

| فایل | کار |
|---|---|
| `persian.js` | نرمال‌سازی متن فارسی/عربی، تبدیل ارقام، یکسان‌سازی نویسه‌های نمایشی PDF، جمله‌بندی هوشمند (چسباندن سطرهای شکسته و ادامه‌ی جمله در صفحه‌ی بعد) |
| `pdf.js` | استخراج متن صفحه‌به‌صفحه با `pdfjs-dist`، حذف سرصفحه/پاصفحه‌های تکراری، تشخیص فصل |
| `analyze.js` | ساخت پروفایل متن: بسامد واژه‌ها، وزن IDF-مانند، کلیدواژه‌های تک‌واژه و دوقطعه‌ای، امتیازدهی جمله بر اساس واژه‌های مهم، جایگاه، نشانه‌های تعریفی و طول جمله |
| `quizgen.js` | ساخت سؤال جای‌خالی با گزینه‌های انحرافی هم‌جنس، سؤال درست/نادرست با جای‌گذاری مفهوم نادرست، سؤال پاسخ کوتاه از جمله‌های تعریفی |
| `pptx.js` | ساخت پاورپوینت راست‌به‌چپ با `pptxgenjs` |
| `llm.js` | اتصال اختیاری به سرویس سازگار با OpenAI |

سرویس یادآور در مرورگر (`public/js/reminders.js`) هر ۲۰ ثانیه رویدادهای پیش‌رو را محاسبه می‌کند،
برای هر رخداد یک کلید یکتا در `localStorage` نگه می‌دارد تا تکراری اعلان ندهد، و در زمان مقرر
اعلان مرورگر + بنر + صدا را اجرا می‌کند.

## API (خلاصه)

| متد | مسیر | کار |
|---|---|---|
| GET | `/api/state` | همه‌ی داده‌های برنامه |
| POST/PUT/DELETE | `/api/courses`، `/api/sessions` | مدیریت درس و جلسه |
| GET | `/api/calendar.ics` | خروجی تقویم (کلاس‌ها + آزمون‌ها با هشدار) |
| POST/PUT/DELETE | `/api/exams` | مدیریت آزمون‌ها |
| PUT | `/api/settings/reminders` | تنظیمات یادآور (زمان، صدا، اعلان) |
| POST | `/api/books` | آپلود PDF (multipart) |
| POST | `/api/books/from-url` | افزودن کتاب از لینک |
| PUT | `/api/books/:id/chapters` | ویرایش فصل‌ها |
| POST | `/api/chapters/:id/summary` | ساخت خلاصه (`depth`, `engine`) |
| POST | `/api/chapters/:id/quiz` | ساخت تست (`count`, `engine`) |
| POST | `/api/chapters/:id/pptx` | ساخت پاورپوینت |
| POST | `/api/chapters/:id/attempt` | ثبت نتیجه‌ی آزمون |
| PUT/POST | `/api/settings/ai`, `/api/settings/ai/test` | تنظیم و تست هوش مصنوعی |

## محدودیت‌های شناخته‌شده

- یادآورهای داخل برنامه تا وقتی Lucky در یک تب مرورگر باز است کار می‌کنند (مرورگرها اجازه‌ی
  اعلان پس‌زمینه‌ی بی‌سرور نمی‌دهند). برای هشدار مستقل از برنامه از خروجی `.ics` استفاده کنید.

- PDF های **اسکن‌شده (تصویری)** متن ندارند و پشتیبانی نمی‌شوند (OCR ندارد).
- کیفیت تشخیص فصل به ساختار فایل PDF بستگی دارد؛ در صورت نیاز از «ویرایش فصل‌ها» استفاده کنید.
- در PDF هایی که ترتیب حروف فارسی در آن‌ها به‌هم‌ریخته استخراج می‌شود، متن فصل قابل ویرایش نیست؛
  این حالت در بیشتر PDF های تولیدشده با نرم‌افزارهای رایج رخ نمی‌دهد.
- فونت فایل پاورپوینت `Tahoma` است تا در همه‌ی نسخه‌های PowerPoint درست نمایش داده شود.
