# پرامپت آماده برای گرفتن کمک طراحی رابط کاربری

این فایل دو چیز دارد: **پرامپتی که به مدل دیگر می‌دهی** و **راهنمای استفاده**.

---

## چطور استفاده کنم؟

1. متن داخل کادر «پرامپت اصلی» را کامل کپی کن و به مدل دیگر (GPT / Claude / Gemini / …) بده.
2. اگر خواستی، **یک اسکرین‌شات از `preview.html`** (یا از خود برنامه) هم ضمیمه کن و بنویس:
   «این وضعیت فعلی است؛ نقد و بازطراحی را بر همین اساس بده.»
3. جواب را **بدون خلاصه‌کردن و کامل** برای من بیاور — همان مارک‌داون را کپی کن.
4. اگر مدل چند «جهت طراحی» پیشنهاد داد، یکی را انتخاب کن و اسمش را بگو؛ یا بگو «هر سه را بیاور تا مقایسه کنیم».

> ⚠️ اگر مدل جواب را با JSX / Tailwind / SCSS داد، به آن بگو: «خروجی باید فقط CSS خالص و HTML باشد؛ دوباره بنویس.»
> اگر هم کد نهایی را خودش ساخت، اشکالی ندارد — من همان را داخل پروژه پیاده و تست می‌کنم.

---

## پرامپت اصلی (این را کپی کن)

```text
# نقش
تو یک طراح ارشد محصول و رابط کاربری هستی، با تخصص در اپلیکیشن‌های فارسی/راست‌به‌چپ، تایپوگرافی فارسی و طراحی مینیمال (سبک «کاغذی»: سطح‌های خنثی، خطوط مویی، بدون گرادیان، بدون سایه‌ی سنگین، یک رنگ تأکید).

# پروژه
«Lucky» — دستیار مطالعهٔ دانشجو، یک وب‌اپ نصب‌شدنی (PWA) که کاملاً آفلاین کار می‌کند.
کارهای اصلی: برنامهٔ هفتگی کلاس‌ها، بارگذاری PDF کتاب هر درس، ساخت خودکار خلاصه/تست/پاورپوینت برای هر فصل، فلش‌کارت با مرور فاصله‌دار (SRS)، آزمون‌ها با یادآور، خروجی تقویم .ics، تم روشن/تاریک.
کاربر: دانشجوی فارسی‌زبان. زبان رابط: فارسی، لحن «تو»، جهت: RTL.

# پشتهٔ فنی (غیرقابل تغییر)
- HTML + CSS + JavaScript خالص با ES modules. بدون فریم‌ورک، بدون build، بدون Tailwind، بدون SCSS، بدون CDN.
- همهٔ استایل‌ها در یک فایل: `public/css/app.css` (~۱۲۷۰ خط) با توکن‌های CSS در `:root` و `[data-theme="dark"]`.
- فونت: وزیرمتن، محلی (woff2). بدون فونت خارجی.
- برنامه داخل iframe با sandbox اجرا می‌شود و شبکه ندارد → هیچ تصویر/آیکن/فونت بیرونی مجاز نیست؛ آیکن‌ها باید SVG درون‌خطی یا یونیکد باشند.
- تست‌ها با jsdom اجرا می‌شوند؛ پس id و کلاس‌های قلاب (فهرست پایین) نباید تغییر کنند یا حذف شوند.
- بودجه: کل CSS زیر ~۴۰ کیلوبایت. انیمیشن‌ها کم و سریع (۱۲۰–۱۸۰ms).

# وضعیت فعلی (طراحی، نه عملکرد)
پوسته: نوار بالای ساده (☰، عنوان صفحه، کلید تم، دکمهٔ «+ افزودن»)، منوی کشویی از سمت راست با کارت اکانت در بالا و آیتم‌ها: برنامه هفتگی، درس‌ها و کتاب‌ها (زیرش فهرست کتاب‌ها)، مرور، آزمون‌ها، تنظیمات. عرض محتوا محدود و وسط‌چین.

توکن‌های فعلی (روشن / تاریک):
  --ink #17171b / #ededf0      --ink-2 #3f3f46 / #c2c2ca     --muted #71717a / #8f8f99
  --bg #fbfbfa / #0e0e10       --card #ffffff / #151517      --surface #f6f6f4 / #1a1a1d
  --line #e7e7e3 / #26262a     --line-strong #d6d6d1 / #35353b
  --brand #2f5bd7 / #8fa9f5    --brand-soft #eef2fd / rgba(143,169,245,.12)
  --ok #0f7b5f    --warn #9a5b06    --danger #b3382f
  --radius 12px  --radius-sm 8px  --radius-lg 16px  --shadow-sm none  --shadow 0 1px 2px rgba(23,23,27,.05)
اندازه‌های متن فعلی: عنوان صفحه ۱۷px، تیتر کارت ۱۴.۵px، متن ۱۳px، زیرمتن ۱۲.۵px، ریز ۱۰.۵–۱۱px.

صفحه‌ها (هر کدام یک تابع رندر مستقل، همه در `public/js/views/`):
1. داشبورد: کارت خوش‌آمد + نام، «مرور امروز»، «آزمون بعدی»، کلاس‌های امروز، میان‌بُرها
2. برنامه هفتگی: نوار هفت‌روزه + کارت خلاصه (تعداد جلسه/ساعت/درس) + فهرست ردیفی روزهایی که کلاس دارند
3. درس‌ها و کتاب‌ها: ستون فهرست کتاب‌ها (۲۸۸px) + پنل کتاب انتخاب‌شده با دکمه‌های عملیات (PDF، خلاصه، تست، پاورپوینت، ویرایش فصل‌بندی، حذف) و فهرست فصل‌ها + کارت درس‌ها
4. صفحهٔ فصل: چهار تب — خلاصه، تست (چندگزینه‌ای + نمره)، پاورپوینت (دانلود/پیش‌نمایش)، متن کامل
5. مرور امروز: فلش‌کارت با «نمایش پاسخ» و چهار دکمهٔ نمره (نمی‌دانستم / سخت / خوب / آسان)
6. آزمون‌ها: کارت «آزمون بعدی» با شمارش معکوس، ردیف‌های فشردهٔ آزمون‌ها، بخش گذشته، ردیف وضعیت یادآور
7. تنظیمات: مشخصات، ظاهر (سه گزینه)، یادآورها (سه سوییچ + دو انتخاب زمان)، هوش مصنوعی (بخش بازشو)، داده‌ها + آمار

قلاب‌هایی که باید حفظ شوند: `#view` `#page-title` `#page-sub` `#topbar-actions` `#menu-btn` `#drawer` `#drawer-backdrop` `#drawer-books` `#account-btn` `.nav-item[data-route]` `#add-btn` `#add-pop` `#install-btn` `[data-theme-btn]` `[data-theme-choice]` `#reminders` `#toasts` `#modal-root` `.card` `.btn` `.btn-primary` `.btn-sm` `.btn-ghost` `.badge` `.input` `.select` `.field` `.label` `.hint` `.meta` `.empty` `.toast`

# خواستهٔ من
یک «سند طراحی اجرایی» بده که من بتوانم مستقیم آن را در همان یک فایل CSS پیاده کنم — نه کد React، نه Tailwind، نه لینک به Figma.

به این ترتیب و با این سرتیترها جواب بده:

## ۱) نقد
۵ تا ۸ ایراد مشخص در وضعیت فعلی (سلسله‌مراتب، تراکم، تایپوگرافی فارسی، حالت‌های خالی، موبایل، دسترس‌پذیری). هر ایراد: مشکل → چرا آزاردهنده است → راه‌حل یک‌خطی.

## ۲) سیستم طراحی
- مقیاس تایپ برای فارسی (اندازه/ارتفاع خط/وزن/کاربرد) با اعداد دقیق
- مقیاس فاصله (پایهٔ ۴px) و شعاع‌ها
- جدول رنگ کامل برای هر دو تم با کد hex و نسبت کنتراست (حداقل AA: ۴.۵:۱ برای متن)
- قاعدهٔ سایه/خط/سطح: کجا خط مویی، کجا سایه
- شبکهٔ چیدمان: عرض بیشینهٔ محتوا، فاصله‌های موبایل/دسکتاپ، نقاط شکست

## ۳) اسپک هر صفحه (هر ۷ صفحه + ۴ تب فصل)
برای هر صفحه:
- وایرفریم ASCII ساده (دسکتاپ و موبایل)
- سلسله‌مراتب: چه چیزی در ۲ ثانیهٔ اول دیده می‌شود، CTA اصلی کدام است
- ردیف/کارت‌های فهرست: ارتفاع، چه اطلاعاتی در چه سطحی از تأکید
- حالت‌های خالی، بارگذاری (skeleton) و خطا
- رفتار موبایل: چه چیزی جمع می‌شود، چه چیزی می‌ماند

## ۴) کامپوننت‌ها
برای هر کامپوننت پرکاربرد (ردیف فهرست، کارت، دکمه‌ها، برچسب وضعیت، نوار پیشرفت، سوییچ، تب، مودال، نان‌بار، کشو، فلش‌کارت، گزینهٔ تست) این‌ها را بده:
- نام کلاس‌ها (BEM کوتاه، هم‌خوان با نام‌های فعلی)
- HTML نمونهٔ کوچک
- CSS خالص و کامل (فقط CSS، بدون preprocessor)
- حالت‌های hover / focus-visible / active / disabled / dark

## ۵) نگاشت
جدولی: کلاس/ساختار فعلی → کلاس جدید (یا «بدون تغییر»). اگر پیشنهاد می‌کنی چیزی حذف یا با چیز دیگری ادغام شود، صریح بگو.

## ۶) دسترس‌پذیری و فارسی
- focus-visible، ترتیب تب، aria برای اجزای تعاملی، هدف لمسی حداقل ۴۴px
- تایپوگرافی فارسی: ارتفاع خط، فاصلهٔ حروف (letter-spacing منفی برای فارسی ممنوع)، شکستن خطوط فارسی، اعداد فارسی، جای علامت‌ها در RTL

## ۷) اولویت اجرا
فهرست ۵ کاری که بیشترین بهبود را با کمترین ریسک می‌دهد، به‌ترتیب.

# محدودیت‌های سخت
- بدون گرادیان، بدون سایهٔ رنگی، بدون افکت شیشه‌ای، بدون ایموجی به‌جای آیکن اصلی (یونیکد ساده یا SVG خطی مجاز است).
- عملکرد و منطق برنامه دست نخورده بماند؛ تو فقط ظاهر، چیدمان و متن‌های رابط را طراحی می‌کنی.
- متن‌های نمونه باید فارسی واقعی باشند (نه Lorem).
- هیچ‌جا از JS برای چیدمان استفاده نکن؛ فقط CSS (grid/flex).
- اگر پیشنهادت نیاز به تغییر ساختار HTML دارد، دقیقاً بنویس کدام تگ عوض می‌شود و به جایش چه می‌آید.

# خروجی
همه‌چیز در یک مارک‌داون، بدون مقدمه و بدون جمع‌بندی. بلوک‌های کد فقط css و html. اعداد دقیق (px/rem)، نه صفت‌هایی مثل «کوچک‌تر».
اگر ابهامی داری، حداکثر ۳ سؤال بپرس و بعد شروع کن.
```

## بعد از گرفتن جواب

جواب را برای من بیاور؛ من این‌ها را انجام می‌دهم:

1. توکن‌ها و مقیاس‌ها را در `public/css/app.css` جایگزین می‌کنم.
2. صفحه‌به‌صفحه چیدمان را پیاده می‌کنم و **همهٔ قلاب‌ها و id ها** را نگه می‌دارم.
3. سه بررسی خودکار را اجرا می‌کنم: `npm run smoke` (۰ خطا)، `npm run audit:css` (بدون کلاس بی‌استایل)، `npm run audit:theme` (کنتراست هر دو تم).
4. `preview.html` را از نو می‌سازم تا خودت ببینی، و کامیت می‌کنم.

اگر جواب مدل خیلی کلی بود (مثل «فاصله‌ها را بیشتر کن»)، همان را به من بگو — من نسخهٔ دقیق و اجرایی‌اش را می‌نویسم.
